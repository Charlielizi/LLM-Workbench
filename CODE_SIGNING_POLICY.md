# Code signing policy

LLM Workbench is open-source software distributed under the MIT License.

Free Windows code signing is provided by SignPath.io, and the certificate is
provided by SignPath Foundation. The signing workflow is executed by GitHub
Actions from the repository's release tag. SignPath's origin verification and
approval policy are the source of truth for which artifacts may be published.

The public release contains the signed `LLM-Workbench-Setup.exe` together with
the matching Squirrel `RELEASES` file and `.nupkg` package generated by the same
build. No private signing key is stored in this repository or in GitHub Actions
secrets.

To report a signing or release-integrity concern, open a GitHub issue in this
repository and include the affected release tag and the SHA-256 hash of the
downloaded artifact.
